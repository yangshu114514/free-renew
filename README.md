# free-renew

[English](README.en.md) | 简体中文

阿贝云 / 三丰云「永久免费云服务器」的自动续期工具。Rust 实现，单二进制，跑在 GitHub Actions 上，你自己的服务器零负载。

> 致谢 [BookerLiu/FreeServer](https://github.com/BookerLiu/FreeServer)（Apache-2.0）——2020 年逆向出了两家的 `cmd=` API 协议，本项目在其基础上重写并扩展。原项目 2021 年因「模板文章无法通过人工审核」停更，本项目的核心改进是 **LLM 生成每篇不同的体验文章**。

## 工作原理

```
GitHub Actions cron（每天，幂等）
  → 登录云厂商 API，查询免费服务器延期状态
  ├── 未到期 / 审核中 → 直接退出（< 1 分钟）
  └── 已到续期日 ↓
      → LLM 生成一篇使用体验文章（角度/长度随机，自动校验合规词表，不合格自动重写）
      → 发文平台发布（当前支持 CSDN，经其 Markdown 编辑器协议）
      → headless Chrome 对文章页截图
      → multipart 提交 文章URL + 截图 到云厂商延期接口
      → 任一步失败 → webhook 通知（可对接 OpenClaw/微信等）
```

关键设计：**每次运行全新登录，不持久化任何 Cookie**——天然免疫两家厂商的短会话有效期。

## 已验证的协议（2026-09）

| 环节 | 状态 |
|---|---|
| 三丰云 `login.php` / `renew.php`（check/list/add） | ✅ 真账号全通 |
| 阿贝云 `login.php` / `renew.php`（境外 IP 需 HTTP 降级） | ✅ 真账号通 |
| CSDN `mdeditor/saveArticle`（HMAC 签名） | ✅ 真账号发文成功 |

两家厂商的响应字段形状不同（数字 vs 中文状态字），解析逻辑按厂商分开实现，详见 `src/cloud.rs` 中 `parse_state` 的实测样本注释。协议细节整理见 `docs/protocol/`。

## 快速开始

### 1. 本地构建

```bash
cargo build --release
```

### 2. 准备配置

```bash
cp config.example.toml config.toml
# 编辑 config.toml，填入云账号、CSDN Cookie、LLM 配置
```

CSDN Cookie 采集（本地有 Chrome，扫码登录一次，自动导出）：

```bash
cargo run --release --bin csdn_cookie_export
```

### 3. 运行

```bash
./target/release/free-renew                 # 读 ./config.toml
./target/release/free-renew --config /path/to/config.toml
```

### 4. GitHub Actions 部署（推荐）

1. Fork / 推送本仓库到你的**私有仓库**
2. 配置仓库 Secrets（与 config.toml 字段对应的环境变量）：

| Secret | 说明 |
|---|---|
| `SANFENGYUN_USERNAME` / `SANFENGYUN_PASSWORD` | 三丰云账号 |
| `ABEIYUN_USERNAME` / `ABEIYUN_PASSWORD` | 阿贝云账号 |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | OpenAI 兼容接口 |
| `CSDN_COOKIES` | CSDN 单行 Cookie（采集器产出） |
| `NOTIFY_WEBHOOK_URL` | 可选，失败通知 webhook |

3. Actions 页面手动触发一次 `workflow_dispatch` 验证链路，之后每天定时自动运行

## 配置项

完整说明见 [config.example.toml](config.example.toml) 内注释。要点：

- `enabled = false` 可临时停用某账号/平台
- `[ai]` 节可自定义生成角度池、字数池、禁词表、必含关键词——**建议按自己的文风改写角度池**，这让每篇文章更个性化
- `creation_statement` 默认 `1`（CSDN「内容由 AI 辅助生成」声明），诚实合规；改为 `0` 的合规风险自担
- 配置优先级：环境变量 > config.toml > 内置默认

## 项目结构

```
src/
├── main.rs           # 流程编排：查状态 → 生成 → 发文 → 截图 → 提交
├── config.rs         # 运行时配置（文件 + 环境变量合并）
├── file_config.rs    # config.toml schema
├── cloud.rs          # 云厂商 API（登录/状态/提交，含双厂商解析差异）
├── csdn.rs           # CSDN 发文（HMAC-SHA256 签名 + saveArticle）
├── writer.rs         # LLM 文章生成 + 合规校验
├── screenshot.rs     # headless Chrome 截图 + 文章就绪轮询
├── notify.rs         # webhook 通知（尽力而为，不阻塞主流程）
└── bin/
    └── csdn_cookie_export.rs  # CSDN Cookie 采集器（本地交互式）
docs/protocol/        # 协议细节整理（三丰云/阿贝云/CSDN）
```
